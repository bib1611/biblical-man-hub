# Voice Preservation Prompts

Prompts specifically designed to check and maintain Biblical Man voice integrity.

---

## 1. Voice Compliance Check (Full)

```
Review this content for Biblical Man voice compliance:

---
[CONTENT]
---

CHECK FOR VIOLATIONS:

**THERAPY-SPEAK** (Automatic red flags)
- [ ] "boundaries"
- [ ] "toxic"
- [ ] "triggered"
- [ ] "trauma"
- [ ] "safe space"
- [ ] "self-care"
- [ ] "validate"
- [ ] "journey"
- [ ] "unpack"
- [ ] "hold space"

**SOFT QUALIFIERS** (Delete all)
- [ ] "I think"
- [ ] "maybe"
- [ ] "perhaps"
- [ ] "sort of"
- [ ] "kind of"
- [ ] "in my opinion"
- [ ] "it seems like"
- [ ] "possibly"

**PROSPERITY GOSPEL** (Remove immediately)
- [ ] "blessed and highly favored"
- [ ] "breakthrough"
- [ ] "abundance mindset"
- [ ] "unlock your potential"
- [ ] "destiny"
- [ ] "manifest"

**STRUCTURAL ISSUES**
- [ ] Long paragraphs (5+ sentences)
- [ ] Missing Scripture integration
- [ ] Scripture dropped without interpretation
- [ ] Missing direct "you" address
- [ ] Passive voice overuse
- [ ] Soft ending (no challenge)

**MISSING ELEMENTS**
- [ ] No working-man metaphor
- [ ] No personal/experiential element
- [ ] No binary choice
- [ ] No confrontational hook

OUTPUT:
{
  "score": X/10,
  "violations": [
    {
      "type": "therapy_speak|soft_qualifier|prosperity|structural",
      "text": "exact text found",
      "location": "paragraph context",
      "severity": "high|medium|low",
      "fix": "specific replacement"
    }
  ],
  "strengths": ["what the content does well"],
  "missing_elements": ["what needs to be added"],
  "priority_fixes": ["most important 3 changes"],
  "overall_assessment": "summary"
}
```

## 3. Voice Injection Prompt

```
Rewrite this SEO content to match Biblical Man voice:

---
[CONTENT]
---

APPLY THESE TRANSFORMATIONS:

1. **RHYTHM**
   - Break up sentences over 20 words
   - Add fragment sentences for punch
   - Create more paragraph breaks
   - Use em dashes for emphasis

2. **DIRECTNESS**
   - Replace "one should" with "you need to"
   - Remove all "maybe/perhaps/I think"
   - Make declarative statements
   - Add "Brother" where appropriate

3. **SCRIPTURE**
   - Add or strengthen KJV verse
   - Don't just quote - interpret
   - Connect to modern struggle
   - Make it structural, not decorative

4. **METAPHOR**
   - Add one working-class image
   - Garbage trucks, not golf courses
   - Calloused hands, not corner offices
   - Physical labor as spiritual metaphor

5. **ENDING**
   - Replace any soft conclusion
   - Add binary choice
   - "Do this or don't" energy
   - Leave a splinter

OUTPUT:
[Full rewritten content]

CHANGES LOG:
- [What was changed and why]
```

## 6. Voice Training Prompt


## 8. Pre-Publication Voice Gate

```
FINAL CHECK before publishing:

TITLE: [TITLE]
META: [META]

---
[FULL CONTENT]
---

GATE CHECKLIST:

✓ or ✗ for each:

**NON-NEGOTIABLES (all must pass)**
- [ ] No therapy-speak terms
- [ ] No soft qualifiers
- [ ] Scripture is integrated (not decorative)
- [ ] Ends with challenge (not soft landing)
- [ ] "You" direct address present
- [ ] At least one working-man element

**STRONG RECOMMENDATIONS**
- [ ] Opening hooks (doesn't start with "In today's world")
- [ ] Staccato rhythm maintained
- [ ] Binary choice in conclusion
- [ ] Em dashes used for emphasis
- [ ] Short paragraphs throughout

**SEO + VOICE ALIGNMENT**
- [ ] Keyword present but natural
- [ ] H2s are direct (not soft phrasing)
- [ ] Meta description has voice

OUTPUT:
- PUBLISH / REVISE
- If REVISE: Specific fixes required
- If PUBLISH: Note any minor improvements for future
```

## Voice Violation Replacement Guide

Quick reference for common violations and their Biblical Man replacements:

| Violation | Replacement |
|-----------|-------------|
| boundaries | lines, limits, "what you'll accept" |
| toxic | poison, corrupt, rotting |
| triggered | provoked, angered, hit a nerve |
| trauma | wounds, scars, "what happened to you" |
| safe space | nowhere is safe - that's the point |
| self-care | stewardship, discipline, "taking care of business" |
| validate | confirm, acknowledge, "tell you what you want to hear" |
| journey | path, walk, fight, road |
| I think | [delete] - state it directly |
| maybe | [delete] - commit to the statement |
| perhaps | [delete] - say it or don't |
| in my opinion | [delete] - all of this is your opinion |
| blessed and highly favored | [delete] - not biblical |
| breakthrough | [delete] - work, not magic |
| unlock your potential | [delete] - prosperity gospel |

- Run Full Voice Check on every piece before publishing
- Use Quick Check during editing process
- Use Voice Injection when repurposing generic content
- Run Consistency Check monthly across recent content
- Use Pre-Publication Gate as final step
- Reference Replacement Guide during editing
